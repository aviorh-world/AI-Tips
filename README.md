# AI Tips · AI לבודקי QA

אתר להרצאה על שימוש ב-AI בבדיקות תוכנה: איך מסקריפט אחד שממלא כתובת מגיעים לבדיקות אוטומטיות מלאות.

## מה יש כאן

| קובץ | מה זה |
|---|---|
| `index.html` | האתר: השיחה עם הצ'אט, 12 סקריפטים שרצים על דף דמו חי, התוסף, דוגמאות לבקשות מ-AI וטיפים |
| `demo-form.html` | טופס דמו עם באגים מתוכננים: חלק מהבדיקות עוברות וחלק נכשלות |
| `qa-companion.zip` | תוסף הכרום QA Companion, מוכן להתקנה |
| `extension/` | קוד המקור של התוסף |

## איך פותחים

- **מקומית:** מורידים את הריפו ופותחים את `index.html`. לא צריך שרת.
- **ברשת:** GitHub Pages מתוך הענף `main`, תיקיית השורש.

## התקנת התוסף

1. מחלצים את `qa-companion.zip`
2. בכרום נכנסים ל-`chrome://extensions` ומדליקים Developer mode
3. Load unpacked ← בוחרים את התיקייה
4. בהגדרות התוסף מוסיפים את הדומיין של סביבת הבדיקות, ואם יש לכם שער AI, גם את הכתובת שלו

הסקריפטים והתוסף מיועדים לסביבות בדיקה בלבד.
