AI לבודקים

מדריך קצר למעבר הדרגתי לעבודה עם AI בבדיקות. כל שלב בונה על הקודם, ואפשר לעצור בכל אחד מהם.

1. הסולם

  1. סקריפט אחד בסימנייה. מזהה אלמנטים בלי לחשוב על קוד.
  2. הקלטה של flow. הבודק מדגים, והמערכת זוכרת את הצעדים.
  3. הצעות ל-AI. מקרים נוספים שהבודק מאשר או דוחה.
  4. סיכום תקלה. ציר זמן של מה שקרה, עם השערה על השורש.
  5. הרצה חוזרת וייצוא. הצעדים הופכים לקוד שנשמר בגרסאות.

2. כללים שלא מתפשרים עליהם

  • לא מדביקים לכלי AI נתוני נישומים, מספרי זיהוי, או כל מידע מוגן. משתמשים בנתונים סינתטיים בלבד.
  • ה-AI מציע והבודק מחליט. שום ציפייה לא נכנסת לבדיקה בלי אישור אנושי.
  • הרצה רק בסביבות בדיקה מאושרות, לא בייצור.
  • אם תשובת ה-AI נראית משכנעת מדי, בודקים אותה מול הדרישה לפני שמאמינים לה.

3. ספריית פרומפטים

לחץ על כל נושא כדי לפתוח. כל פרומפט מכיל מקומות למילוי בסוגריים מרובעים.

מקרי בדיקה מדרישה 
להלן דרישה: [הדבק דרישה]. צור מקרי בדיקה בעברית: חיוביים, שליליים, גבולות, ומקרי קצה. לכל מקרה: תנאי מקדים, צעדים, תוצאה צפויה. אל תמציא שדות או כללים שלא הופיעו בדרישה.
חיפוש חורים בכיסוי 
הנה רשימת מקרי הבדיקה הקיימים: [הדבק]. והנה תיאור הפיצ'ר: [הדבק]. מה לא מכוסה? סווג את החסרים לפי סיכון, והצע מקרה אחד לכל חסר.
ניסוח באג 
הנה שלבי השחזור הגולמיים: [הדבק]. הנה ההודעה שמופיעה: [הדבק]. נסח באג בעברית: כותרת, סביבה, שלבי שחזור ממוספרים, תוצאה צפויה, תוצאה בפועל. אל תוסיף עובדות שלא הופיעו.
ניתוח לוגים 
להלן שגיאות מתוך הלוג (מסווים): [הדבק]. קבץ לפי סיבה אפשרית, ציין את השגיאה הנפוצה ביותר, והצע שלוש השערות לשורש. סמן כל השערה כהשערה.
נתוני בדיקה סינתטיים 
צור 10 רשומות בדיקה סינתטיות לטופס עם השדות הבאים: [רשימת שדות]. השתמש בשמות ובכתובות בעברית שאינם שייכים לאנשים אמיתיים. אל תשתמש במספרים שנראים כמו מזהים אמיתיים.

4. סקריפטים לקונסול הדפדפן

להרצה ב-DevTools, בלשונית Console, בסביבת בדיקה בלבד.

אלמנטים בלי שם נגיש 
[...document.querySelectorAll('button, a, input, select, textarea')]
  .filter(el => !(el.innerText?.trim() || el.getAttribute('aria-label') || el.labels?.length || el.title))
  .map(el => ({ tag: el.tagName, id: el.id, class: el.className }))
רשימת שדות טופס עם התוויות שלהם 
[...document.querySelectorAll('input, select, textarea')].map(el => ({
  name: el.name || el.id,
  type: el.type,
  label: el.labels?.[0]?.innerText?.trim() || el.getAttribute('aria-label') || '',
  required: el.required,
  maxlength: el.maxLength > 0 ? el.maxLength : null
}))
בקשות רשת שנכשלו בדף הנוכחי 
performance.getEntriesByType('resource')
  .filter(r => r.responseStatus >= 400)
  .map(r => ({ url: r.name.split('?')[0], status: r.responseStatus }))
תמונות שבורות 
[...document.images].filter(img => !img.complete || img.naturalWidth === 0).map(img => img.src.split('?')[0])
מבנה דף מקוצר להדבקה בפרומפט 
(function outline(el = document.body, depth = 0, out = []) {
  if (depth > 4) return out;
  const tag = el.tagName.toLowerCase();
  const text = (el.childNodes.length === 1 && el.firstChild.nodeType === 3) ? el.textContent.trim().slice(0, 40) : '';
  out.push('  '.repeat(depth) + tag + (el.id ? '#' + el.id : '') + (text ? ' "' + text + '"' : ''));
  [...el.children].slice(0, 15).forEach(c => outline(c, depth + 1, out));
  return out;
})().join('\n')

5. תרגיל של 30 דקות

  1. בחר מסך אחד מהמערכת שלך, או את מסך הדמו של התוסף.
  2. הרץ את סקריפט אלמנטים בלי שם נגיש, ורשום את הממצאים.
  3. בקש מה-AI מקרי בדיקה מתוך הדרישה, בלי נתונים אמיתיים.
  4. סמן כל מקרה: מאושר, נדחה, או דורש תיקון. ספור כמה מקרים חדשים עלו לך.
