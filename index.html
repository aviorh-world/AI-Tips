✨

        
כותרת: הכפתור "חזור" במסך אימות SMS לא מגיב

    🗄️ שאילתות DB שעובדות בפעם הראשונה
    

      
ה-AI לא רואה את ה-DB שלכם, אז הוא מנחש שמות של טבלאות ועמודות. במקום לתת לו לנחש, נותנים לו את המפה. מריצים את זה בסביבת הבדיקות ומדביקים לו את התוצאה:

      

        
כל הטבלאות והעמודות (מבנה בלבד, בלי נתונים)

        
SELECT TABLE_NAME, COLUMN_NAME, DATA_TYPE, IS_NULLABLE
FROM INFORMATION_SCHEMA.COLUMNS
ORDER BY TABLE_NAME, ORDINAL_POSITION;

      

      
ובנוסף, את כל התוכן של טבלאות קטנות וקבועות, כמו סטטוסים, סוגי בקשות וערים. את אלה הוא באמת לא יכול לנחש:

      

        
טבלה סטטית, במלואה

        
SELECT * FROM Statuses;

      

      

        
🙋‍♂️

          
הנה מבנה הטבלאות [מדביק], והנה כל טבלת הסטטוסים [מדביק]. תכתוב שאילתה שמוצאת בקשות שתקועות בסטטוס "ממתין לאימות" יותר מיום.

          
        

        
✨

          
SELECT a.ApplicationId, a.CreatedAt
FROM Applications a
WHERE a.StatusId = 3
  AND a.CreatedAt < DATEADD(day, -1, GETDATE());

          
מטבלת הסטטוסים ידעתי ש"ממתין לאימות" הוא 3, אז לא הייתי צריך לנחש.

        

      

      
💡 ומשם זה רק משתפר: "מילאתי טופס ולחצתי שמור. תכתוב שאילתה שבודקת שהכל נשמר נכון." או: "תכתוב שאילתה שמנקה את נתוני הבדיקה שיצרתי היום." (את זו קוראים לפני שמריצים.)
